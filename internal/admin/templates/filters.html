{{icon "info"}} How filtering decides
  1. Hide is checked first. If a Hide Deny rule wins, the video never appears: no title or thumbnail anywhere, and a direct link shows “not available”.
  2. Otherwise Block decides. If a Block Deny rule wins, the video shows in lists with a lock and the kid can ask you for it. Otherwise it plays.
  3. Within a tier, the most specific rule type wins: Video → Channel → Keyword → Category → Attribute → kid's default. At each step, rules for a specific kid beat rules for all kids, and Deny beats Allow.

Examples: Block-Allow keyword “minecraft” + Hide-Deny keyword “creepy” → “Creepy Minecraft” is hidden. Hide-Allow a video + Block-Deny the same video → it shows up but needs your OK.
