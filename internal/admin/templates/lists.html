{{icon "info"}} How shared lists work

Filter lists are maintained by others (like ad-block lists) and update automatically once a day. Pick the ones that fit each kid's age.

For each list choose what it does: Block (default) shows matching videos with a lock so the kid can ask you; Hide removes them completely; Mixed follows the list author's choice for each entry (some hidden, some blocked).

Your own entries always win over a list's entry of the same type. For example, if a list hides the keyword “fortnite”, adding “fortnite” to your own Hide → Allow keywords shows those videos again. The usual order still applies (video → channel → keyword → category → attribute), so to override a list's channel entry, add that channel (or video) yourself. The Rule tester shows which list decided.

Lists can also contain Allow entries; those are counted separately below, so you can see if a list loosens anything.
