{{icon "devices"}} Console name

Shown on each kid PC's Security page, next to the console's access token, so you can tell what has access.

{{icon "globe"}} Phone access

Use the console from your phone or another computer while it's running here. Works on your home network and over a VPN (e.g. Tailscale or WireGuard); connections from the internet are always refused.

Anyone who logs in here controls every paired PC, so use a password your kids can't guess. If the phone can't connect, the computer's firewall may need to allow the port: Windows asks the first time (allow “Private networks”); on Linux with a firewall turned on, run sudo ufw allow {{$ph.Port}}/tcp.

{{icon "key"}} Password

The console's own login, separate from the kid PCs'. Changing it signs out every device. Forgot it? Run ytguard console passwd on this computer.
