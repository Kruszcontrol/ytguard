{{icon "info"}} How this works

Mixed (default) follows the list author's choice for each entry — clearly inappropriate videos are hidden, borderline ones blocked so the kid can ask. Block everything shows every match with a lock; Hide everything removes them all. Your own filter entries always win over a list's.

Apply to all PCs subscribes PCs that don't have the list yet and updates the ones that do. If you pick particular kids, a PC with none of them doesn't get the list (and it's turned off there if it had it).
